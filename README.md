# TestIT
## Цель приложения -- оценка hard skills потенциального сотрудника
## Сделано совместно с [Преподавателем](https://github.com/11qfour)
### Приложение TestIT может:
1. Задавать вопросы и автоматически оценивать ответы
2. Давать заключение о результате прохождения теста
3. Подсчитывать время потраченное на тест
4. Разбито логически на несколько модулей
